# Simple Web Calculator

A straightforward web-based calculator built with HTML, CSS, and JavaScript. It features a colorful UI and basic arithmetic functionalities, along with a handy multiplication table generator.

## Features

* **Basic Arithmetic**: Performs addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`), and modulo (`%`).
* **Multiplication Table Generator**: Generates a complete multiplication table for the first input number, up to the multiplier specified in the second input.
* **Clear Functionality**: Quickly reset both input fields and the result display using the "clear" button.
* **Input Validation**: Displays an alert prompting the user to fill in the remaining fields if any inputs are left blank.
* **Interactive UI**: Buttons and input fields feature a solid border with box-shadows, complete with dynamic hover and active click animations.
* **Custom Styling**: Uses a `paleturquoise` background and custom typography for a clean, bold look.

## Project Structure

* `index.html`: The main markup file containing the page layout, number inputs, and operation buttons.
* `script.js`: Contains all the logic for mathematical operations, rendering the table with HTML `<br>` tags, and clearing the inputs.
* `style.css`: Defines the visual design, layout alignments, and interactive element transitions.

## How to Use

1. Clone or download this repository to your local machine.
2. Open the `index.html` file in any modern web browser.
3. Enter your starting number into the **Enter First Number** field.
4. Enter your second number into the **Enter second Number** field.
5. Click on any of the operator buttons to calculate the result, or click `table` to generate a multiplication table.
